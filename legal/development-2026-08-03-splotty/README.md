# Splotty development legal set

These documents replace the Orca-named development set for founder and
internal TestFlight testing. They are not approved for external testers,
production, or App Store submission.

Each database document hash is the lowercase SHA-256 digest of the
corresponding Markdown file's exact UTF-8 bytes. Published replacements must
use a new immutable version and require a new acceptance; never edit an already
accepted version in place.
